# Word list: patterns that read as machine-written

Patterns, not banned words. "Key" is fine in "API key"; "landscape" is fine for a painting. The linter flags
figurative uses where it can; you decide.

## Inflated vocabulary (use the plain word or cut)
| Pattern | Instead |
| --- | --- |
| delve, deep dive | look at, read, check |
| leverage | use |
| utilise | use |
| boasts | has |
| seamless, seamlessly | say what actually happens, or cut |
| robust | say what it withstands |
| tapestry, testament, journey (figurative) | cut |
| pivotal, crucial, vital | important, and say why |
| underscore, highlight (as verbs for ideas) | show |
| showcase, showcasing | show |
| foster, fostering | build, encourage |
| empower, unlock, elevate | let, allow, improve (with a number) |
| cutting-edge, game-changing, revolutionary, next-level | cut |
| vibrant, intricate, meticulous, multifaceted | cut, or be specific |
| navigate (the complexities of) | handle, deal with |
| in the ever-evolving landscape of | cut |
| additionally (opening a sentence) | also, or start a new paragraph |

## Constructions
- "It's not just X, it's Y" / "not only X but also Y": say what it is.
- "Whether you're a beginner or an expert": cut.
- "In today's fast-paced world": cut.
- "Stands as a", "serves as a": "is".
- "Plays a crucial role in": say what it does.
- Opening chat: "Certainly!", "Great question", "Absolutely". Closing chat: "I hope this helps", "Let me know if".
- "In conclusion", "Overall,", "In summary," at the end of a short text: cut the recap.

## Punctuation and layout
- Em dashes: at most one per paragraph.
- Emoji used as bullets or before headings.
- Bold on several phrases in one paragraph.
- Title Case Headings: use sentence case.

## Proof
- "Trusted by thousands", "10,000+ users", "industry-leading", "best-in-class": give a source and date, or cut.
